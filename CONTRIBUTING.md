# Contributing

Contributions are welcome.

1. Open an issue for bugs or behavioral changes so the expected result is clear.
2. Keep HA Probulator Home Assistant-native and avoid external service dependencies unless they are essential to the requested feature.
3. Preserve normal Home Assistant entities as the source of truth. Custom cards must not become the only way to access monitoring data.
4. Run the repository validation steps before submitting a pull request.
5. Do not include credentials, private hostnames, public IP ownership information, or Home Assistant configuration exports in issues or tests.

Pull requests should explain what changed, why it changed, and how it was tested.
